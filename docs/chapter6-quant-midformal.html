We have developed propositional logic, and expanded it to predicate logic. We now continue the project. This time we expand predicate logic to what is called first-order logic.

This chapter introduces the intuitions and ideas. In the next chapter we will study the formal syntax and semantics.

Keep R\Bbb RR in Your Heart

Throughout this chapter it will help to keep in mind how you would develop a language to talk about the real numbers.

Recall that the real numbers can be thought of, roughly, as “every possible decimal expansion”. The decimal expansion, for example, of 3/2 is 1.5. And the decimal expansion of 1/3 is the infinite expansion 0.333…

Later we’ll have more to say about decimal expansions and the formal construction of real numbers. But at least for now, this is a simple start to thinking about the real numbers.

Some examples: Every integer and rational number is a real number. But then there are some real numbers, like 2\sqrt 22​ and π\piπ, which are real numbers but not rational. Later in this course we will actually prove that 2\sqrt 22​ is real but not rational, whereas proving this for π\piπ is beyond the scope of this course.

Note that 2\sqrt 22​ doesn’t look like a “decimal expansion”. But there is a sequence of decimal numerals which is equivalent to 2\sqrt 22​.

2=1.4142...\sqrt 2 = 1.4142... 2​=1.4142...

Now what does this have to do with logic?

First of all notice that the “number of real numbers” is enormous. It is clearly infinite, and bigger than the rational numbers in the sense that the rational numbers are a subset of the real numbers. In fact, this doesn’t even fully capture the way in which the real numbers are bigger than the rational numbers — we’ll have more to say about that later.

But one thing is clear: Our language cannot, in any practical sense, name every single real number. Of course each real number is an infinite decimal sequence — you might therefore argue that one can regard the decimal sequence as the “name” of the number.

However, that’s not practical. We can only practically write down finitely many digits of any decimal expansion. We will never fully name any number, if we name it by its decimal expansion.

Alternately, we can name a real number by symbols like 2\sqrt 22​ and π\piπ. These names fully identify the number, without an infinite representation. When we write 2\sqrt 22​, this refers to the exact number — in a sense, referring to its entire completed decimal expansion.

But for all practical purposes, our collection of names can only be finite. And yet there is an infinity of real numbers, and we will often want to reason about all of them, or certain infinite subsets of them.

In this chapter we will introduce “quantifiers”, which will allow us to easily reason about sets which are either large or infinite. In particular we will discuss the syntax and semantics of our expanded logical system.

Some of the ways that we define our semantics, in particular, may seem odd and complicated. Many of the complexities of first-order semantics are due to the issues raised by the real numbers: The need to have a reasonably small collection of names, while trying to reason about a very large infinite set. So keep this example in mind as you read the rest of this chapter.

“All” and “Some”

Consider a sentence like “every dog deserves pets”.

If we were to express this in predicate syntax, first we would need a name for every dog. That would be a lot of names, like

d1,d2,d3,...,d109{\tt d_1},{\tt d_2},{\tt d_3},...,{\tt d_{10^{9}}} d1​,d2​,d3​,...,d109​

for each of about a billion doggies. Then we need a predicate, like D(x){\tt D}({\tt x})D(x), to represent "x{\tt x}x deserves pets".

Then we need to form the very long conjunction

D(d1)∧D(d2)∧⋯∧D(d109){\tt D}({\tt d_1}){\tt \land} {\tt D}({\tt d_2}){\tt \land}\cdots{\tt \land} {\tt D}({\tt d_{10^9}}) D(d1​)∧D(d2​)∧⋯∧D(d109​)

But in English, the sentence is much simpler and shorter—we just use a phrase like “all”.

"All doggies deserve pets."

Much simpler!

Of course there is a parallel idea for disjunction: Consider the sentence “Some chimpanzee deserves pets.” This one might deserve pets:

This one gives me "no pets" vibes.

To express “some chimps deserve pets” we’ll need to name every chimp,

c1,...,c106{\tt c_1},...,{\tt c_{10^6}} c1​,...,c106​

and then assert

D(c1)∨⋯∨D(c106){\tt D}({\tt c_1}){\tt \lor}\cdots{\tt \lor} {\tt D}({\tt c_{10^6}}) D(c1​)∨⋯∨D(c106​)

The point being that “all” indicates a long conjunction of a predicate, over every individual in the domain. “Some” indicates a long disjunction of a predicate, over every individual in the domain.

The above only considers a finite domain, like the set of all doggies or the set of all chimps.

But in math we’ll often need to discuss an infinite domain, like in the sentence “Every number divisible by 4 is divisible by 2.” The natural domain for this statement is the set of integers, and so we are claiming

“If 0 is divisible by 4 then 0 is divisible by 2, and if 1 is divisible by 4 then 1 is divisible by 2, and if -1 …”

This is like an “infinitely long conjunction”, although an actual infinitely long sentence is not possible. Therefore we need a system of finite expressions, which is able to make claims about an infinite domain.

Of course we could repeat much of this for disjunction. In the sentence “there is an integer larger than π100\pi^{100}π100” we are essentially saying “either 0 is larger than π100\pi^{100}π100, or 1 is larger than π100\pi^{100}π100, or -1 is larger than π100\pi^{100}π100, or …”

Whenever we want to make a claim about all objects within the domain, we call this “universal quantification”. This is indicated by words like “all”, “every”, “each”, and so on.

Whenever we want to make a claim that there is some object within the domain, we call this “existential quantification”. This is indicated by words like “there is”, “there exists”, “some”, and so on.

Quantifiers

We are now going to add quantifiers to our predicate logic. The result is called first-order logic, which we officially define later.

To express “every dog deserves pets” in first-order logic, we will write

∀xD(x){\tt \forall} {\tt x} {\tt D}({\tt x}) ∀xD(x)

The upside-down ‘A’ is read as “for all”. So the literal reading of this expression is

For all x{\tt x}x in the domain, x{\tt x}x deserves pets.

This expresses that all dogs deserve pets, so long as the "domain of discourse" is the set of all dogs. If the domain were all chimps, then ∀xD(x){\tt \forall} {\tt x} {\tt D}({\tt x})∀xD(x) would express that all chimps deserve pets.

To express “some chimp deserves pets”, if the domain is all chimps then we would write

∃xD(x){\tt \exists} {\tt x} {\tt D}({\tt x}) ∃xD(x)

The backwards 'E' is read as "there exists". So the literal reading of this expression is

There exists an x{\tt x}x in the domain, x{\tt x}x deserves pets.

The symbols ∀{\tt \forall}∀ and ∃{\tt \exists}∃ are called "quantifiers".

Notice that the syntax uses a variable, like x{\tt x}x above. However, we still want to have constant symbols, as we did with predicate logic. Variables and constants mean very different things! A variable "varies", i.e. takes on the value of several different domain elements. A constant has its meaning fixed to one specified domain element.

For example, suppose that the domain is all integers, o{\tt o}o denotes the number 1, and the predicate D(x,y){\tt D}({\tt x},{\tt y})D(x,y) denotes the relation "x{\tt x}x is divisible by y{\tt y}y".

We can continue to use the semantic notation from the previous chapter, and write

म=Zoम=1Dम={(x,y)∈Z2:x is divisible by y}\begin{aligned} म &= \Bbb Z\\ {\tt o}^म &= 1\\ {\tt D}^म &= \{(x,y)\in\Bbb Z^2: x \text{ is divisible by } y\} \end{aligned}मoमDम​=Z=1={(x,y)∈Z2:x is divisible by y}​

Then to express that every number is divisible by 1, we write

∀xD(x,o){\tt \forall} {\tt x} {\tt D}({\tt x},{\tt o}) ∀xD(x,o)

Both variables and constants will be represented by lower-case letters, as you see above. And yet our logical language will need two kinds of object symbols, one for variables and one for constants, and we don't want them to get confused for each other.

Traditionally we will use the letters a{\tt a}a through t{\tt t}t for constants, and the letters u{\tt u}u through z{\tt z}z for variables. Of course we also allow indices, so that a101{\tt a_{101}}a101​ and t0{\tt t_0}t0​ may be constants, and u123{\tt u_{123}}u123​ could be a variable.

Not only can we quantify over formulas, but in fact, we can make formulas out of quantified expressions. For example, if the domain is integers, E{\tt E}E denotes "is even", O{\tt O}O denotes "is odd", then the expression

(∃xE(x))∧(∃xO(x))\tt (\exists x E(x)) \land (\exists x O(x)) (∃xE(x))∧(∃xO(x))

expresses that "there is some number which is even, and there is some number which is odd". This is a true proposition, since there does exist an even integer, 2, and there does exist an odd integer, 3.

Note how different this expression is from the seemingly similar expression

∃x(E(x)∧O(x)){\tt \exists} {\tt x}({\tt E}({\tt x}){\tt \land} {\tt O}({\tt x})) ∃x(E(x)∧O(x))

This says that there exists an integer, x{\tt x}x, which is both even and odd. That is not true, of course, since any number which is even cannot also be odd.

Nested Quantifiers

Things get more interesting still when we consider multiple quantifiers.

Consider the domain of all humans on the planet, and the relation L(x,y){\tt L}({\tt x},{\tt y})L(x,y) which represents “x{\tt x}x loves y{\tt y}y”.

Now consider the different meanings of each of the following propositions.

  • ∀x∀yL(x,y){\tt \forall} {\tt x}{\tt \forall} {\tt y} {\tt L}({\tt x},{\tt y})∀x∀yL(x,y) "Everybody loves everybody" like a utopia.
  • ∀x∃yL(x,y){\tt \forall} {\tt x}{\tt \exists} {\tt y} {\tt L}({\tt x},{\tt y})∀x∃yL(x,y) "Everybody loves somebody" like the Dean Martin song.
  • ∃x∀yL(x,y){\tt \exists} {\tt x}{\tt \forall} {\tt y} {\tt L}({\tt x},{\tt y})∃x∀yL(x,y) "Somebody loves everybody" like a Jesus figure.
  • ∃x∃yL(x,y){\tt \exists} {\tt x}{\tt \exists} {\tt y} {\tt L}({\tt x},{\tt y})∃x∃yL(x,y) "Somebody loves somebody", a statement that love is not dead.

I hope that the above gives you an intuition for what the quantifiers mean and how their order can impact the meaning of an expression.

Note

These two tables are structured differently.

Where is the predicate indicated? Well, there's no room for it now that both rows and columns are taken up. So the predicate is indicated by the entire table (not just one row of the table).

So the two tables are not meant to be read in exactly the same way.

Therefore, if AAA and BBB are sets, then to state that A⊆BA\subseteq BA⊆B is the same as the proposition

∀x(x∈A→x∈B)\forall x(x\in A\to x\in B) ∀x(x∈A→x∈B)

Of course, to say that any two sets are equal is simply the conjunction of two subset statements. In symbols, A=BA=BA=B if and only if A⊆BA\subseteq BA⊆B and B⊆AB\subseteq AB⊆A. In our logical formalism, A=BA=BA=B is equivalent to

∀x(x∈A→x∈B)∧∀x(x∈B→x∈A)\forall x(x\in A\to x\in B)\land \forall x(x\in B\to x\in A) ∀x(x∈A→x∈B)∧∀x(x∈B→x∈A)

It is worth wondering: Is this equivalent to ∀x(x∈A↔x∈B)\forall x(x\in A\leftrightarrow x\in B)∀x(x∈A↔x∈B)? Intuitively the answer is "yes". It says that "for all objects in the domain, if it is in AAA then it is in BBB, and if it is in BBB then it is in AAA". We will see a rigorous proof of this fact later.

Here is another worthwhile observation: Suppose that we set the domain to be all cats, and then want to express "All cats are mammals.". Yes, we could continue to represent this as ∀x(C(x)→M(x))\forall x(C(x)\to M(x))∀x(C(x)→M(x)). However, with the domain being set to all cats, this now just means the same as ∀xM(x)\forall x M(x)∀xM(x). For now this is an idle observation, although when we discuss the idea of "types" we will make more use of this idea.
