# Chapter : Quantifier Proof Theory

Some inference with quantifiers are obvious. For example, from $\forall x P(x)$, if *a* is any object symbol then we can infer $P(a)$ This is called “universal instantiation” or “universal elimination”.

For the existential quantifier, the other direction is easy. From $P(a)$ we can infer $\exists x P(x)$. This is called “existential generalization” or “existential introduction”. 

The rule is easy, and the logic of its correctness is also easy to appreciate. 

The rules going in the other direction (universal introduction and existential elimination) are more complicated, so let's first warm up to them by recalling some examples.
